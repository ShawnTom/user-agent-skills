# AI 资讯月度收集 v1.0

> 每月一次的 AI 行业深度情报整理。覆盖**国内外大模型公司**、**制造业 + AI**、**AI 新应用范式**、**月度趋势分析**四大板块，最终输出到飞书知识库。结构上与周报（`ai-news-collector`）保持一致的字段体系，但深度、宽度、聚合度均显著提升。

---

## 任务卡（TL;DR）

| 项 | 值 |
| --- | --- |
| **输入** | 当前日期 + 上次月报（如有） |
| **输出** | 一份飞书文档，写入目标知识库 |
| **覆盖范围** | `today - 30` ~ `today`（含追踪延续） |
| **覆盖公司** | 国内 9 家 + 国外 3 家 + 制造业 3 家 |
| **质量门禁** | 9 项硬性自查，必须全过 |
| **预计耗时** | 30–60 分钟（含网络抓取） |

## 输入约定

### 时间窗口

- **默认范围**：`today - 30` ~ `today`（含端点）
- **追踪延续**：本月内出现重大事件**贯穿**周报多条时，必须做**完整时间线聚合**
- **超期事件**：超过 30 天但仍在产生后续影响 → **标注原始日期**，并写明"最新进展（YYYY/MM/DD）"
- **跨月处理**：若月报执行日跨月 → 仍以"当前月"为主，覆盖到 30 天前

### 上下文

执行前应**先询问用户**或**读取**以下信息：

1. **当前日期**（用于计算时间窗口；默认 2026-07-08）
2. **上次月报链接**（如存在 → 用于"延续追踪"）
3. **本次执行是否要写飞书**（默认是；可指定 dry-run 仅生成 Markdown）
4. **覆盖月份**（默认：当前月；可指定"2026 年 6 月月报"等）
5. **是否需要英文版**（默认否；如需要则同时输出中文+英文双版本）

#### 月度评分规则（vs 周报强化版）

**评分维度（总分 10）**：

| 维度 | 权重 | 评分依据 |
| --- | --- | --- |
| **创新性** | 35% | 提出新概念 / 改变共识 / 跨范式融合 |
| **可操作性** | 25% | 有具体方法论 / 决策树 / 代码示例 |
| **时效性** | 15% | 本月首发 / 反映最新趋势 |
| **传播性** | 10% | 行业有讨论 / 多人引用 |
| **持久性** | 15%（**新增**） | 是否有后续跟进 / 跨周延续 / 引用增长 |

**入选标准**：
- 总分 ≥ 7.5 才考虑入选
- 入选 Top 12-15 时**优先保证多样性**（不要 12 条全是"Agent 架构"主题）
- 优先选**有原文 + 可点击链接 + 跨周引用**的条目

### Part 4：月度趋势分析（**本 skill 独家**）

> **月报区别于周报的核心价值**：把过去 30 天的事件**串成趋势线**。

#### 4.1 资本趋势

- 本月融资总额 / 轮次分布 / 估值中位数
- 头部公司估值变化
- 一级市场 vs 二级市场动态
- 海外资本动作

#### 4.2 技术趋势

- 模型能力跃迁（如多模态、长上下文、推理）
- 架构创新（MoE / SSM / Hybrid 等）
- 训练范式（RLHF / DPO / Self-Play 等）
- 评测基准变化

#### 4.3 格局趋势

- 国内「AI 六小虎」格局变化
- 头部 vs 长尾分化
- 国产替代进展
- 海外巨头进入中国策略

#### 4.4 政策趋势

- 国内监管动态（备案、内容、版权、跨境）
- 海外监管（EU AI Act、美国行政令、英国 AISI 等）
- 行业标准制定
- 政府采购/国资入场

### Part 5：跨周事件时间线（**本 skill 独家**）

> 把本月内**贯穿多周**的重大事件做完整时间线聚合。

**示例**：

```markdown
### OpenAI → Anthropic 价格战时间线

- 2026/06/15：OpenAI 宣布 GPT-5 API 降价 50%
- 2026/06/18：Anthropic 推出 Claude 4.5 Opus，定价低于 GPT-5 30%
- 2026/06/22：Google Gemini 3 Flash 降价跟进
- 2026/06/25：OpenAI 推出"按 Token 阶梯定价"模式
- 2026/07/02：Anthropic 推出 Enterprise Pool（企业池化定价）
- 2026/07/05：Google 推出 AI Studio 免费层

**格局意义**：2026 H2 大模型 API 正式进入"价格战 + 池化定价"双轨。
```

## 注意事项

- **避免幻觉**：找不到来源时，**宁可标"本月无重大更新"，也不要编内容**
- **链接必须可点**：直接写完整 URL
- **日期精确**：用 `YYYY/MM/DD` 格式
- **多语言**：国内源用中文标题，国外源保留英文原文标题
- **冲突处理**：同一事件多源报道时 → 优先级 `官方源 > 一线媒体 > 社区讨论`
- **趋势分析的数据**：必须基于本月内的事件，**不**引用 3 个月前的事件作为"本月趋势"
- **跨周事件时间线**：必须基于最近 4 期周报（每期 7 天），时间线跨度不超过 30 天
- **月度报告 ≠ 4 期周报拼贴**：月报必须做**聚合 + 提炼 + 趋势判断**，不是简单拼接
